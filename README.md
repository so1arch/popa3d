# N64 Parkour

Браузерный 3D-паркур в стиле Nintendo 64 (three.js + Vite).

## Что в игре

- **Монеты обязательны.** Звезда открывается, только когда собраны все монеты уровня (пока закрыта, она серая и проволочная). Время и рекорд засчитываются только при взятии открытой звезды.
- **Магазин.** За пройденный уровень вы получаете столько монет, сколько их было на уровне. Их можно тратить на улучшения прыжка и скорости (по 10 уровней). Прогресс хранится в браузере (localStorage).
- **Небо и облака.** Процедурный скайбокс (солнце, облака в вышине, море облаков внизу) и динамические облака, которые плывут по ветру, «дышат» и растворяются рядом с камерой.
- **Редактор.** 14 форм платформ (прямоугольник, круг, шестиугольник, ромб, треугольник, полукруг, крест, L, T, зигзаг, звезда, кольцо, подкова, ступени), у каждой своя ширина, глубина, поворот, наклон (пандусы) и толщина.

## Управление

Игра: WASD бег, пробел прыжок, V первое лицо, Q/E, стрелки и мышь камера, R заново, M меню.

Редактор:

| Действие | Как |
|---|---|
| Поставить | клик ЛКМ |
| Стереть | клик ПКМ (или инструмент «Стереть») |
| Вращать камеру | тянуть ЛКМ |
| Двигать камеру | тянуть ПКМ или среднюю кнопку (или Shift + ЛКМ) |
| Приблизить / отдалить | колесо мыши |
| Высота плоскости построения | Shift + колесо, либо Z / X |
| Повернуть платформу | R (Shift+R в другую сторону) |
| Вся карта | F или кнопка «Вся карта» |
| Отмена | Ctrl + Z |
| Инструменты | клавиши 1–5 |

Для понимания глубины: сетка лежит на высоте, где окажется объект; от призрака вниз идёт жёлтая линия до поверхности под ним, на которой рисуется тёмная «тень»-проекция; сверху экрана написано, на сколько объект выше платформы под ним. Если включено «Прилипать к верху платформ», курсор сам берёт высоту платформы, на которую вы наводитесь.

## Запуск у себя

```bash
npm install
npm run dev      # откроется локальный сервер
npm run build    # сборка в папку dist
```

## Как выложить на GitHub Pages (играть по ссылке github.io)

Структура репозитория должна быть такой:

```
.github/workflows/build.yml
src/main.js
src/shapes.js
src/sky.js
src/clouds.js
.gitignore
index.html
package.json
vite.config.js
README.md
```

1. Зайдите на github.com, нажмите **New repository**, придумайте имя (например `n64-parkour`), выберите **Public**, нажмите **Create repository**.
2. Загрузите файлы. Проще всего так: на странице пустого репозитория нажмите **uploading an existing file** и перетащите `index.html`, `package.json`, `vite.config.js`, `README.md` и папку `src`. Нажмите **Commit changes**.
3. Файлы с точки в начале имени (`.gitignore` и папка `.github`) через перетаскивание часто не загружаются, поэтому создайте их вручную: **Add file → Create new file**. В поле имени введите `.github/workflows/build.yml` (слэши сами создадут папки), вставьте содержимое файла `build.yml`, нажмите **Commit changes**. Так же создайте файл `.gitignore` с двумя строками: `node_modules` и `dist`.
4. Включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Перейдите на вкладку **Actions**. Должен запуститься **Build and Deploy** (занимает 1–2 минуты). Если он запустился раньше, чем вы включили Pages, откройте его и нажмите **Re-run all jobs**, либо выберите **Run workflow**.
6. Когда сборка станет зелёной, ссылка на игру будет в **Settings → Pages**, а также в задаче `deploy`. Формат ссылки:

   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

То же самое через командную строку:

```bash
git init
git add .
git commit -m "N64 Parkour"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Дальше любое обновление файлов в ветке `main` автоматически пересобирает и публикует игру.

### Если что-то не работает

- **Actions не запускается.** Workflow слушает ветку `main`. Если ваша ветка называется `master`, переименуйте её или поменяйте `branches: [main]` в `build.yml`.
- **Ошибка при деплое про Pages.** Не выбран источник **GitHub Actions** в Settings → Pages (шаг 4). После этого перезапустите workflow.
- **Белый экран по ссылке.** Нажмите Ctrl+F5. В `vite.config.js` должно быть `base: './'` (так и есть), тогда игра работает из подпапки `/имя-репозитория/`.
- **Мастерская (уровни игроков).** Уровни берутся из Issues этого же репозитория: игрок нажимает «Отправить в Мастерскую», создаётся Issue; когда вы его одобряете, добавьте ему метку `workshop`. Работает только на github.io.

### Ссылки на уровни

Кнопка «Скопировать ссылку на уровень» даёт ссылку вида `.../#S=сид` или `.../#L=код`. Старые ссылки и коды (платформы из пяти чисел) продолжают работать, а новые коды дополнительно хранят форму, поворот, наклон и толщину.
